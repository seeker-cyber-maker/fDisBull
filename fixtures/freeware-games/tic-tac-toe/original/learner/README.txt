Ancient TicTacToe - adapted DOS build

ATTT.COM is a NASM syntax adaptation of Sai Kurogetsu's Ancient TicTacToe, upstream commit f6cd09a59a75cfe24fe15d654c4362ed11bfd6c3 (https://github.com/lunakurame/ancient-tictactoe). It is not an exact upstream TASM/TLINK build. Original license: LICENSE (Unlicense). The separate source/evidence package contains the original, adaptation, build instructions and tests.

Two human players alternate. Player 1 (x): Q W E / A S D / Z X C. Player 2 (o): 7 8 9 / 4 5 6 / 1 2 3. An occupied square or wrong player's key does not move. At a win or draw press any key for a new round; Esc quits during play. Run ATTT.COM in DOS or compatible DOSBox.
