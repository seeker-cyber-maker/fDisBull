# Compact native behavior batch

`tests/test_qemu_agi_behavior_batch.py` checks representative interactions on an
explicitly supplied, already-built AGI native executable. It uses synthetic
bytecode and catalog geometry. It does not build a runtime, load original game
assets, complete a draw, or replace the existing exhaustive acceptance suites.

The batch groups compatible behavior in one immutable program and validates
intermediate committed transitions from its SCENE journal. Observation variants
reuse the same owned child through restart. Faults, profile changes and startup
admission failures retain separate children because those boundaries cannot be
crossed by changing an observation control.

## Required inputs

- `FDISBULL_QEMU_AGI_INTENT`: explicit executable path.
- `FDISBULL_QEMU_AGI_EXPECTED_SHA256`: expected lowercase binary SHA-256.
- `FDISBULL_QEMU_AGI_EVIDENCE`: existing caller-owned directory for receipts,
  stopped state/journal snapshots and bounded native failure diagnostics.

Without an executable selection, ordinary pytest collection skips this native
test. Selecting a binary without its expected hash is a failure. A dedicated
gate controller must require a completed receipt; a missing-backend skip is
not qualification.

Run only this module through a controller that enforces the whole-gate deadline:

```sh
python -m pytest -q -x -p no:cacheprovider tests/test_qemu_agi_behavior_batch.py
```

The controller should set `PYTHONDONTWRITEBYTECODE=1`, provide private temporary
and evidence directories, and preserve stdout, exit status and the receipt. It
must supervise and clean up the owned QEMU children as well as pytest: each
native harness creates a separate process session. Do not automatically retry
a failed or timed-out gate.

## Finite scope

| Group | Children | Run calls |
| --- | ---: | ---: |
| Binding geometry, ordinal retention/fallback, animation, historical operands | 1 | 6 |
| Cycling and deferred draw, including frozen continuation and journal controls | 1 | 8 |
| Invalid actor atomicity | 1 | 2 |
| Unbound draw atomicity | 1 | 2 |
| Scalar-profile draw rejection | 1 | 1 |
| Binding-profile draw rejection | 1 | 1 |
| Intent startup without a catalog | 1 | 0 |
| Malformed catalog magic | 1 | 0 |
| **Maximum and expected completed gate** | **8** | **20** |

Both behavior bundles run masks 0, 1, 2 and 3 and capacities 0 and 1. Their
complete guest states must agree, including pending effects where present.
Literal authored actor states specify every intermediate change; helpers frame
those expectations with byte offsets and journal fields, without interpreting
native binding semantics or invoking a production decoder.

The active admission window is 50 seconds, leaving cleanup time within the
required external 60-second whole-gate limit. QMP deadlines are five seconds.
Every configured execution budget is at most 128 retirements. Complete journals
use capacity 256. No TCG operation logs are generated by this routine gate.

The binding program has one authored return. The intent program ends at its
first draw, preserves an explicitly out-of-bounds committed position, and
leaves a following sentinel assignment unexecuted. Direct continuation must
preserve the complete stopped state and run counters. Clearing or configuring
observations must preserve guest state. Restart must restore the complete
initial guest while retaining immutable code/catalog/profile identity.

## Receipts and reuse

`batch-receipt.json` records actual constructor attempts, spawned PIDs, run
calls, native invocation IDs, native/wall timing, exact program/catalog hashes,
binary and test/harness source hashes, outcomes, exit codes and reaping status.
Each run's state and each checked journal are retained alongside it. Expected
startup failures retain the production harness's bounded diagnostic directory.
Counts are derived from observed work; completion checks detect skipped groups.

The executable is checked against the caller's hash before work, for each
admitted child, and after the gate. Relevant source files are hashed before and
after. Existing wrapper checks continue to bind every observed state/journal
to the immutable authored program, selected profile and admitted catalog.

This is a selective interaction gate. It does not renew exhaustive malformed
catalog, operand-range, truncated-encoding, all-opcode compatibility or TCG
instrumentation qualification. Reuse existing results for the same qualified
binary and contracts; rerun affected exhaustive groups when those inputs
change. Scene-consumer or report changes do not by themselves require repeating
the whole native opcode catalog.
