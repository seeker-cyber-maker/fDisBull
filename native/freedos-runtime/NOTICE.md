# FreeDOS 1.4 runtime component

This component uses the FreeDOS 1.4 kernel and FreeCOM from the official
FreeDOS 1.4 repository. The accompanying original upstream package archives
include source; their binary members match the official floppy input. Kernel
and FreeCOM identify their licenses as GNU GPL version 2; retain the full
upstream packages and notices when redistributing. The boot sector comes from
FreeDOS 1.4 floppy media. This is not a legal determination that all obligations
for any later modified distribution have been satisfied.

The runtime image, configuration and archive are generated separately from
source. The component contains no project target, game files or session state.
Runtime boot and hard-disk conversion require independent native validation.
