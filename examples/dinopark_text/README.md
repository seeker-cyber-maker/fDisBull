# DinoPark CLI shims

The maintained implementations and sampled recognition profiles ship inside
`fdisbull`, so installed packages do not depend on this examples directory.

- `python -m fdisbull.dinopark_z`: original-backed UDC service for Z.
- `python -m fdisbull.dinopark_scenes`: original native scene CLI.

The Python files here are checkout-only compatibility entry points. See
[DinoPark Z](../../docs/DINOPARK_Z.md) for prerequisites, commands, evidence
and current limits. Bring your own qualified original game and native backend.
