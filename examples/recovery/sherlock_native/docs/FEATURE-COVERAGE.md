## What this ledger establishes

The application is authored as Objective-C/AppKit presentation over portable C player state, a native numbered-puzzle table reader and a native SHI codec. The application contains no DOSBox, Wine, DOS executable, CPU instruction decoder or runtime dependency on the original program. Offline recovery tools are separate from this application.

**This is not a macOS execution receipt or a claim of complete original equivalence.** The portable C code has been compiled and exercised on Linux. The AppKit sources have been reviewed but have not been compiled against an Apple SDK, launched on a Mac, or driven through the GUI. Original behavior has been qualified only at the boundaries identified below. The complete 65,536-puzzle data resource has passed exhaustive export, native reader and player-state integration checks. The source refuses an unavailable puzzle instead of substituting another generator.

This ledger covers every one of the 70 requirements in `research/sherlock-feature-contract.md`. Its source references use the section keys defined there. That contract derives from the supplied complete `SHERLOCK.DOC`, including its 1.50/UK revision entry. One original observation improves the manual's general description: reference-only image cards can also occupy horizontal slots.

Status vocabulary:

- **Implemented**: the requested logical operation has an implementation. This does not imply unperformed target-platform testing.
- **Native presentation adaptation**: the operation is implemented through native windows, controls, dialogs or file services with an explicitly different presentation.
- **Partially implemented**: an operation exists, but a listed requirement, exact original rule, or required qualification remains open.
- **Unimplemented**: no implementation exists for the named operation. Missing subfeatures are also identified explicitly within partially implemented rows and in the gap list.

Every GUI row below still shares the macOS execution gate. The evidence column distinguishes state/media evidence from source inspection of UI wiring.

## Deliberate native policies and material gaps

The original main-menu title, factory-color menu artwork and small bitmap font are now recovered resources. The portable font and menu composition have original-pixel witnesses. Native settings screens, help-page sequence, custom-color frames, dialog chrome and full Mac output remain adaptations or unqualified. The game uses original SHI pixels, clue composition and the supplied pause image. Native dialogs handle text input, file selection, errors and editing. Standard system alerts/file panels use macOS button semantics; custom game/editor controls implement secondary-click actions.

The native hint engine and support verifier are independently authored and answer-free. Displayed-bank ordering for three relation families and acknowledgment-time fee/timeout boundaries now have original witnesses. The timer display freezes during the pending hint while elapsed time still counts. Full original selection/prose and hidden-answer error repair remain different. Native stronger all-clue deductions and free non-action messages are declared policies. Proof reports explicit unresolved status when its budget cannot establish consistency or the fixed deduction.

The original victory movement is implemented and independently compared with original instruction execution. Post-generation RNG was not exported with the numbered table, so the app uses a stable native initial state and native presentation pacing; any key can skip after the current burst. Generation progress pitch sweep, original CFG interoperability and exact DOS help-page presentation remain unimplemented. The six recovered action sounds, including reuse of the choose cue for victory bursts, do not establish analog or sample-identical audio.

The eleven original color roles/default values and sixteen background preset data blocks are now recovered and used. Native frame/text rendering, pattern phase on AppKit and precise background gesture behavior still need target/original comparison.
