# DinoPark public-guide meta-review: reconciliation with current evidence

This is a claim audit, not a new original-game experiment or a fresh survey of every external guide. The supplied text remains unchanged. No engine, Swift project, original game file or remote repository was changed.

## Assessment

The strongest contribution is the proposed executable annotated guide: preserve each public claim, identify its platform/build, attach its testable mechanism, and retain qualifications and counterexamples. Its external-source inventory is useful as supplied, but its comparison with our work repeatedly uses the much older v5 recovery report. Several "open" items were subsequently tested or mapped. This audit prevents those stale boundaries from becoming duplicate investigations.

The source-reported NEW GAME profit run is a potentially important independent project milestone. It reports a $4,028 completed-month result, repaid debt and $10,506 cash with Desert / Coelophysis / Wood / one guide / twenty small-feeder units. This audit did not retrieve the named standalone receipt from GitHub or Library. Keep those figures attributed to the supplied review until the receipt and trajectory are reconciled. A profitable month and a first-year survival recipe have different outcome horizons.

## Method changes

Keep three separate attributes: claim verdict, evidence scope, and independence/provenance. Static inspection plus our own bounded execution is useful corroboration, but not independent replication or full graphical-route proof. Public-source repetition is not independent corroboration when claims share wording or provenance.

For strategy tests, identify the objective and duration before ranking policies. Use the unchanged lab to screen possibilities, then validate representative policies in the original game. Record whether shared RNG changes are part of the tested action: forcing identical random returns after an information/menu excursion would erase part of that excursion's actual effect.

Player-facing advice should use UI-reachable prices. The formula's $9.75 threshold and illustrative $4.99/$5.01 values are not normal click-selectable settings. Within the existing source ordering, advertisements follow the initial capacity/reach minimum; do not add an unobserved final cap.

## Suggested order

First consolidate already-supported mechanics and obtain the other agent's normal-play receipt. Then run an exact starter recipe and a small seasonal ticket-policy comparison, with the short Ctrl+1 claim checked opportunistically. Use scene definitions to close only the remaining live auction/land variants. Leave the timing-sensitive guide-underflow claim behind ordinary gameplay acceptance rather than making it a prerequisite for graphics/audio work.

QuickStart identity and Mac/3DO-specific claims remain platform/provenance questions. A successful DOS result does not qualify a separate platform automatically.
