# Reviewed research artifacts

**Research-only derivatives; not runnable or reopening-equivalent original projects.** See [AUDIT.md](AUDIT.md) for exclusions and limitations.

This layout repackages the exact 1,448-file reviewed subset: 1,432 documents, 9 rebuilt SQLite gzip exports, 5 Zork semantic JSON gzip exports, and the original audit/catalog. No original archive, game executable, raw target image, media, or game-source/build package is added.

## Reading and verification

- Fourteen key reports are readable under `documents/`.
- Nine rebuilt database gzip files remain under `databases-derived/`; five semantic UIL/IR gzip files remain under `zork-derived/`.
- Seventeen ZIPs under `document-packs/` contain only individually reviewed documents. Source ZIP labels describe provenance: these are **not** the original source ZIPs. Each ZIP retains full reviewed-relative member paths.
- `PACKAGED-CATALOG.json` records every reviewed loose file and ZIP output hash, exact member paths/hashes, and source hashes. `catalog.json` preserves the reviewed source lineage and transformation details.
- Historical receipts/checksums refer to original packs and are not validation of these incomplete derivatives.
- The authored Algorithm Lab HTML is an active semantic simulator retained as an explicitly reviewed document, not an original-game payload. No bundled code was executed during repackaging.
