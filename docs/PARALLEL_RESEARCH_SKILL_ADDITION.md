# Suggested investigation-skill addition: parallel research workspaces

Status: proposed addition for reconciliation with the accepted methodology.
This document does not install a new skill or provide an existing CLI command.

Treat a research workspace as a task-bound runtime, target-filesystem and evidence
branch. A source worktree alone does not isolate a guest, a save directory or an
analysis database. Choose static/shared-observation work when execution is not
needed; choose a private or hybrid linked clone for independent interventions.

Before parallelizing, specify one unresolved question per worker, a common pinned
starting point, the minimum state needed, permitted changes, expected observations,
stop conditions, budget and output contract. Three workers is a convenient default,
not a reason to create a third investigation that contributes no independent value.

One controller owns each live instance. Readers use coherent published snapshots.
Never share writable guest RAM, writable save directories, input queues or breakpoint
ownership between independent trials. Shared immutable inputs and accepted evidence
are useful; private hypotheses and declared blind trials remain separate.

A clone requires an observed identity and qualified persistence boundary. Native
save, emulator checkpoint, semantic snapshot and static input set have different
coverage. A child which changes inputs, preserves RNG across rewind or patches
state is an experimental branch, not the parent's unchanged recorded future.

When the backend has a qualified independent restore/replay route, rewind in a sibling to keep the reference progressing. Otherwise report that capability as unavailable and use supported static or serial observations. A previously unrecorded
past cannot be recovered just by cloning the present. Reproduction requires a
suitable earlier anchor and enough controlled or recorded input/environment state.
Report divergence before attaching a child result to a particular original event.

Return a compact claim/evidence packet with source, capsule, branch, event, entity
and method identities. Compare at matching logical boundaries, not host wall time.
Promote findings independently from code and runtime state. Never paste a worker's
RAM into the current reference as a generic merge. Revalidate any proposed action
plan against the reference's current conditions.

Measure capture cost and resource interference on the reference. On failure, hold
or close only the owned child, preserve partial evidence, and never replay its input
on the reference. Retire only artifacts and processes whose ownership is known;
retain shared ancestors while children or reproducibility receipts reference them.
