## Attributed route leads

Robb names SCM for Shield, Chest, Mirror. His basic configuration is DOSBox ECE
r4319, Tandy, 60K cycles, with a harder 63K variation; the input lists assume
favorable encounters and giant RNG. The gnome segment combines `HI`, `GET KEY`
and F3 repetitions. Section 3.5 recommends Return followed almost immediately
by 6 to stop on the gnome screen's left side. Section 3.4 similarly uses Return
then 4 to stop on the giant screen's right side, seeking a favorable chest
approach; the route then uses `GET CHEST`. The June guide uses a walnut payment
route and explains preparing the F3 buffer. These are runner techniques and
practice estimates, requiring qualification in another runtime. See PDF pages
1–3 and 8 for details.

The video narration separately describes three wrong gnome guesses yielding
the key at [4:23](https://youtu.be/KPlKetNSAtE?t=263), and shield protection,
giant sleep and chest pickup at [6:13](https://youtu.be/KPlKetNSAtE?t=373).

## Evidence boundary

This June guide is a different route from the
[later 9.89 TAS reconstruction](../kq1-robb-9.89/ROUTE.md), whose preserved
recording reports 157600 cycles and shows a bag/diamonds payment. Neither source
is an exact input script or native verification for the other.

Manual English captions were acquired with complete timing coverage under the
fetcher's check; wording was not independently checked against audio. A
bounded public-comment sample found the pinned uploader comment was
sponsorship text. The description supplies the document link.

[source-provenance.json](source-provenance.json) records the source chain,
page/timestamp locators, acquisition scope and retained source hashes. Only
authored prose and provenance are included here. The PDF, captions, video,
images, raw HTML and private acquisition corpus remain outside Git. This
research performs no native gameplay qualification.
