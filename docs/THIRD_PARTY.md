# Third-party engines

Dependencies are installed separately; their upstream licenses apply. This source archive does not vendor their source or native wheels.

- iced-x86 1.21.0: https://github.com/icedland/iced
- Capstone Python distribution 5.0.9: https://github.com/capstone-engine/capstone
- LIEF 1.0.0: https://github.com/lief-project/LIEF
- Pillow (tested 12.3.0): https://github.com/python-pillow/Pillow
- pytest (test dependency): https://github.com/pytest-dev/pytest

The first-party project has no distribution license selected in this initial handoff. Choose one before distributing it as an open-source project.
