## Adapter and recovery contract

The shared CLI/Z land handler retains one order ID, original run, source street
revision, before state, phase, queued input receipts and any native commit proof.
The six original click points and their order are preserved. Each next control
receives separate pointer movement and 150 guest milliseconds of preparation,
followed by fresh source, balance, allocation and release checks before its
press. A 250-millisecond execution attempt then consumes the queued press/release;
readiness is polled rather than inferred from a fixed long delay.

Z starts the shared 40-second host budget before request observation. The land
helper inherits that deadline; each phase has a cumulative 16,000-millisecond
requested-guest allowance across continuations. Host and guest preparation
allowances are checked before queuing pointer movement. A composed run exception
is not classified as wholly undispatched. Uncertain execution suppresses the
ordinary continuation while retaining read-only reconciliation when eligible.

`look` exposes `continue land purchase` only for an eligible held order. It
resumes the recorded phase and sends later inputs, never its last delivered
press. The recovery ID remains that of the original `buy desert plot` action.
After completion, `reconcile` checks the paused original effect, street and
released pointer, then issues the original canonical `buy` / `plot` certificate
with a fresh witness. It requests no input, execution or restore. An unqualified
read leaves the hold intact, and retries preserve the original diagnostic.
Commit evidence is recorded before the first post-commit display read.

## Friction to carry into the next implementation

- Author scene-family samples independently of the original software cursor.
  Preserve content/readiness and native-effect gates; an animated or occluded
  sample is not permission to relax every scene predicate.
- Admit host and cumulative guest preparation before queuing movement. A failed
  continuation must not add pointer events when its remaining allowance is known
  insufficient.
- Apply shared action deadlines and retained phase/commit receipts to legacy
  fence and other long purchase paths. Observer composition must intersect the
  caller deadline rather than replace it with a larger allowance.
- Keep transport connection failure, owned-provider lifetime and completion
  evidence distinct. A caller timeout must not be presented as a native crash,
  rollback or successful shutdown; late readback needs explicit request binding.
- Normalize equivalent call forms for attribution while preserving actual bytes
  and ABI assumptions. A fixed five-byte far-CALL lookback misses compiler
  sequences that construct the same callee-entry return stack.
- Version evidence-export schemas and distinguish durable certificate fields
  from transient controller state. One private verifier initially expected a
  `STATE.land_commit` field that was not serialized; it was corrected to the
  retained certificate without changing a guest operation or result.

## Additional retained-call attribution

Parent review then investigated the three current filename origins that the
five-byte far-CALL collector had left unknown. Each is a STRINGS.DAT call whose
raw callee PC is `2182:00ef` and return pair is `2182:002d`. Original code at
`295e:0029` saves CS and calls near with displacement `00c2`, reaching offset
`00ef` from return offset `002d`. Saving CS first produces the captured far-return
stack layout. The preceding NOP belonged to the old five-byte lookback, not the
actual four-byte call sequence.

A bounded parent pass followed the three hash-linked filename exports, totaling
906 captured argument snapshots. It kept all 852 already-qualified encoded far
calls and identified the same `PUSH CS; CALL rel16` form in all 54 previously
unqualified snapshots: 51 baseline plus three current, all for STRINGS.DAT.
Raw return CS/IP, current callee CS/IP, 16-bit real mode, original bytes and the
runtime/static mapping match each case. This closes those 54 *captured filename
origin classifications* under the stated ABI assumptions; it closes none of the
97 inventory entries or 13 asset candidates.

Luna independently checked the written overlay, its three packet hashes, the
906/852/54 accounting and one concrete return/target example. That was an offline
spot check, not a second full per-row derivation or another native experiment.

Historical exports and their unknown counts are preserved. The new normalization
is a separate derived overlay. It is an attribution correction to the private
collector's five-byte-only assumption, not evidence that the production decoder
could not decode a near call. The normalized form is equivalent at the observed
callee-entry return-ABI boundary; it is not a claim of instruction, interrupt,
fault or timing equivalence, and no original code was rewritten.
