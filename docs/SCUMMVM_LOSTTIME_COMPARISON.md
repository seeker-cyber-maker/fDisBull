# Lost in Time: original DOS, Gob and fresh Z authoring

The experimental Gob adapter runs the qualified English US v1.10 DOS CD slice
with source-bound script control, typed state, actual input and stored frames.
Both new Z reconstructions pass the same independent bounded assessment after
one correction each. This is a usable local experiment, with a separate patched
ScummVM sidecar; it is not a released fDisBull payload or whole-game recovery.

The [metadata comparison](evidence/scummvm-gob-2026-11-01/comparison.json) and
[implementation verification](evidence/scummvm-gob-2026-11-01/verification.json)
preserve identities, measurements, grades and limits. Original game resources,
native databases/states, screenshots, authored game-text exports and judge
controllers remain in the private experiment workspace, outside tool packages.

## Existing models and actual runtime behavior

The original-DOS oracle executes the original x86 interpreter. The separately
built Gob sidecar executes ScummVM 2026.4.0's replacement Inter_v3 interpreter
over the original resources. The native sidecar is pinned to upstream commit
`7d2709da5136866589f7602f5f5a7b17de03420e` and binary SHA-256
`b350172eec8e797cfe5c9ffec05c19b06cd84470210a83a0e443871bc43ccd98`.

A fresh Gob run passed 43 guarded ordinary-input cases covering the poster,
stool/underside/nail, lamp, oil, water, pump, drainage and return. A separate run
passed 25 explicitly assisted cases. Original DOS separately qualified those
selected response/state rules. Fourteen selected native/model comparisons cover
all seven existing branch models: poster, water first/repeat/small-pipe, and
pump stuck/gentleness/work. All nine declared retained-field comparisons agree.
These are selected response leaves and terminal retained-effect projections;
omitted callers, menus, animation and passthrough fields are not full-handler
equivalence claims. Diagnostic item selections do not prove natural ownership.

First water response presentation precedes the checked-flag commitment at
acknowledgment. Pump drainage can commit before the final presentation closes.
Input readiness, visible text, retained state and UI dismissal were checked at
their respective boundaries. Fixed waits alone were insufficient for some Gob
popups. Qualified clicks checked the actual active rectangle, current source,
input status and committed display. Gameplay was 320x200 at coordinate scale1;
the 640x400 title is a real mode change rather than a presumed 2x input scale.

## The nail view

The early hold stool nail is distinct from the later cabin nail and desk-chair
key. Its local rectangle exists before the underside view opens. A table entry
therefore cannot establish current visibility. The tested binding requires the
current source, camera/subview, enabled active rectangle and current popup
origin. Closing hides it; reopening at another point changes the origin and
requires a new target resolution. The new Z models pass the wrong-view,
close/reopen and bare-hand refusal checks. Natural extraction is outside scope.

## Matched fresh authoring

Two new local-context investigators received the same task and original inputs,
one assigned DOSBox and one Gob. They could use generic tool/schema/interpreter
sources, but prior Lost in Time solutions and the other investigator/judge were
prohibited. General model knowledge and file access were not experimentally
controlled. DOS received a prequalified exact-edition arena binding; Gob used
its native state and hotspot interfaces. Adapter construction, gold preparation
and generic launcher preparation were excluded prework. Each trial's fresh
copy/boot time was charged. Each author used three fresh ordinary-input runs.

Both recreated the connected hold/poster/stool/nail/lamp/oil/bilge/water/pump/
drain/return slice as real shared-IL scenes through the Z protocol and installed
player. First submissions, failed versions, native evidence and later repairs
were frozen separately. An independent judge used a rubric frozen before
author inspection, its own controllers, original DOS evidence and fresh Z/player
processes. The judge did not accept author self-validation as the final verdict.

The same first-stage error appeared in both reconstructions. With empty hands,
an already-oiled undrained pump operates directly from the wide view after its
detail is closed. Both models instead reopened the detail and required another
operate action. The judge confirmed the counterexample in a new original-DOS
run using a fresh private mount. Both authors corrected that exposed branch,
preserved the oil-item distinction, and passed the same regression criteria.
The first grades and erroneous exports remain unchanged in the private record.

The Gob author's two phases total about 2m50s less, or 8.7%, in this pair.
That workflow also spent less time inside public runtime calls. Review gaps and serial grading are
separate; raw confirmation time is not an engine-speed ranking. Call granularity,
capture strategy and script organization differ. DOS used one fresh helper for
generic schema work, whose 14 wrapped commands are included. Each author hit
one pre-dispatch measurement-helper argument error before the common fix. DOS
also has one command-start without a completion receipt and a separately
reported note-shell quoting error. These remain explicit accounting limits.

This is one matched pair rather than a general productivity result. The scenes
are authored partial projections, not automatic UDC output, exhaustive state
recovery, or proof that all native branches are represented.

## Rendering and preservation limits

The final-build9 completed-bilge image pair differs at 42,851 of 64,000 pixels;
42,775 differences are only 1-3 RGB levels and 76 are larger. The underside pair
has the same 76 larger differences. Palette expansion and cursor alignment are
plausible contributors; no normalization or pixel-parity assertion was used.

Native Gob exact save/load checkpoints and loaded-script patches remain
unsupported. Input manifests initially refuse symlinks; other language/media
sets need separate qualification. Watches cover instrumented accessors and omit
direct-pointer and uninstrumented stream paths. The event/trace rings are capped;
truncation does not prove unseen handler completion.

One earlier DOS diagnostic reused its own older private mount and normal game
execution changed its `cat.inf`. Original targets and checkpoint bytes remain
intact, but the historical matching progress-file bytes were not recovered from
owned copies or serialized checkpoint streams. That older dry checkpoint's mount
restoration remains unqualified. All final comparison and authoring runs use
fresh isolated mounts; this limitation does not qualify the older state for reuse.
