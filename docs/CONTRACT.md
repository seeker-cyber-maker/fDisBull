# fDisBull 0.4 acceptance contract

Provide a local, agent-first disassembly database: parse recoverable executable information; retain byte versions; recursively discover code/data under explicit rules and budgets; allow shared address annotations/representations; render stored findings without a GUI. Imported files are never executed.

Classic DOS MZ is now a first-class input. Validate fixed fields, page/header/relocation bounds and supported memory limits. Load at an explicit segment (default `0x1000`), apply fixups, retain source bytes, and zero-fill only paragraph padding/minimum allocation. Exclude header/overlay bytes from loaded code. Do not fabricate PSP memory, DOS allocator/runtime state or A20 wrapping.

Decode MZ with actual CS:IP semantics. Near branches preserve CS and wrap the offset; far branches carry their own selector. Separate CS-specific interpretations at the same physical address. Unknown register/segment/index states must not produce invented flat references. Make calling-convention, interrupt and deferred-seed assumptions inspectable.

Run entry recursion first. Admit relocation-backed far-call patterns, observed-data-segment callback pointers and paired literal far-pointer initialization as later **candidates**, preserving provenance. Never classify every relocation or whole candidate segment as code. `segments` reports inferred roles/bounds; `code-regions` reports only contiguous decoded facts per CS.

Persist and deduplicate code/data work. A budget stop remains explicitly incomplete; resumption may reach `stable` only when implemented queues drain. Stability does not prove all original instructions, functions, indirect targets or dynamic overlays have been recovered.

Names/comments/representations belong to versioned physical addresses and resolve in every referring query/export. A representation change retracts derived facts and triggers bounded reanalysis, or leaves work queued when deferred. It never changes the byte version or digest. Explicit `unexplored` definitions hold ranges out of automatic code/data investigation until reclassified. Patching creates a child while retaining parent bytes/metadata/annotations. Reverse all MZ fixups in reverse order for retained file-backed child bytes; keep allocation-only edits memory-only. Inherited interpretations require semantic review.

Expose byte ownership without decoding implicitly: return every stored instruction/data/definition span containing an address, context aliases and overlaps, byte offset, `begin`/`part`/`end`/`single`, inclusive end and exclusive next address. Provide native function-prologue/epilogue/return/tail-exit evidence with candidate status and qualification. Optional unexplored-byte scans must be bounded, retain separate provenance and leave facts/queues unchanged. A pattern is not proof of a function boundary or permission to promote an entire region.

Analyze a DLL/shared library only when explicitly requested, from a local retained snapshot. Support a unique mapped export name/ordinal or preferred virtual entry, reject forwarded exports requiring another module, and persist selected roots through reanalysis. Permit modules without executable entries without inventing an entry instruction. Do not execute an initializer, load imported DLLs or imply runtime dependency resolution.

Recognize CLR metadata without optional dependencies and keep invalid recognized payloads explicit. Guard pure-IL/invalid CLR from accidental native entry analysis. Optional dnfile/dncil support may inspect managed metadata and decode bounded real CIL methods with token/call and local branch references. Keep assembly/method tokens, IL offsets, RVAs and native addresses distinct. Report partial/invalid bodies, unsupported native/runtime methods, precompiled/mixed-mode limits and missing dependencies. Do not claim C# reconstruction, full EH/type/stack verification or actual Godot ALD qualification without the matching assembly and fresh evidence.

Offer read-only x86 decoder comparison over fixed bytes and bounded alternative starts. Preserve both engines' validity, consumed length, text, mode/options and versions. Do not execute generated bytes, select a decoder as hardware authority or promote agreement to code/semantic proof. SNO x86 synthesis, hardware CPU fuzzing and the Apple-container/Wine debugger remain researched proposals with explicit missing qualification, not implemented runtime capabilities.

Retain prior flat ELF/PE/Mach-O/raw behavior and offline CHimpREC-derived recovery. Static imports and captured-IAT reconstruction remain separate. Recovery retains aliases/unknowns and does not attach to Windows or rebuild a runnable executable.

Verify synthetic relocation/segmentation/state/alias/version cases, malformed inputs, schema 1/2 migration, existing format regressions and public protocol/render behavior. Exercise byte-span ownership, candidate-only scans, representation defer/release and unchanged byte identity, module root persistence, managed metadata/CIL separation and bounded decoder disagreements through public seams. Exercise the actual original DinoPark EXE through import, bounded recursive resumption, segment/code-run inventories and known `38ff:*` routines; report measured evidence separately from assumptions. Record difficult-corpus search/access limits instead of claiming unavailable samples were tested.

Do not claim full game execution, every-instruction coverage, runtime overlay recovery, complete CFG/function boundaries, decompilation, unrestricted data flow, runtime SMC capture or macOS runtime verification. No new simulator or guest-code execution belongs to this milestone.
