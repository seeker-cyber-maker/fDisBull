# Bottom-row bridge evidence

[receipt.json](receipt.json) binds the portable collector/exporter, skill changes,
two fresh native sessions, the installed-player check and the focused Linux run.
[observations.json](observations.json) retains selected coordinates, flags and
source priority values. It is a sampled state trace, not an instruction trace.
The three PNGs are unedited native last-completed frames, without text/EXIF
chunks. Frames and separately read memory are not asserted atomic.

The completed candidate reaches room40, dry, alive and neutral with an idle
keyboard. The adjacent control stops at the first observed water flag while
still moving left. Earlier candidate collector stops at the west border and
new-room initialization are preserved in private evidence and summarized in the
receipt; they are not relabeled original-game failures.

The Linux [test summary](linux-tests.log) records386 passing checks on
Python3.12.16/aarch64. Genuine pinned dependencies were used; iced-x86 was built
with a task-private Rust toolchain. The full build/runtime logs remain private.
This is focused local Linux coverage, not hosted/full-native acceptance.

[container-service-bridge.patch](container-service-bridge.patch) records the
local Apple Container1.6.1 launch-path repair. Before/after hashes and20 host
checks are in the receipt; the exact authored checks are retained as
[container_guard_checks.py](container_guard_checks.py). This support patch is
inspectable evidence, with no automatic application or installer change to
fDisBull. It preserves external bulk storage and internal launch plists.
The original backup and reversible marker-recovery records remain private.

Game/story resources, states, databases, complete native captures/journals,
generated scene/provenance, rootfs data and toolchains are excluded from Git.
See [the route and methodology](../../AGI_BRIDGE_BOTTOM.md).
