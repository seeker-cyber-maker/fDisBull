# Syndicate history and recipient damage evidence

Reports: [native findings](https://chatgpt.com/library?file_id=libfile_07414ad9ef808191842d0650969bb02b&account_id=personal) and
[integration contract](../../WORLD_HISTORY_DAMAGE_CONTRACT.md).

These files combine authored tools, semantic fixtures and historical native
observations. No original executable, asset, memory image, checkpoint, game
screenshot or analysis database is included.
The standalone handoff additionally contains semantic-only SQLite event journals
and the global diagnostic world snapshot; those are deliberately absent here.

Run `PYTHONPATH=examples/syndicate_z_scene/tools python -B -m unittest discover
-s examples/syndicate_z_scene/tests -v` with the installed Player available.
Run `stress_history.py /path/to/new-output` with the same PYTHONPATH for the
10,003-record authored load check. Native scripts require the privately supplied
originals, source-bound controller configuration and a newly owned prepared guest;
set SYNDICATE_HISTORY_WORKSPACE and PYTHONPATH explicitly. Their historical
source-identities paths name the handoff, not repository locations.

The collector watches selected recipient sinks, not all projectile creation.
The contact/car scripts produce immutable native trace receipts; their later
conversion to semantic causal history is explicitly retrospective.

`qualified-other-damage-sanitized.json` is a derived fixture, not a byte-identical
historical receipt. It omits 32 raw before/after preparation values (80 bytes
across 16 recorded edits), while retaining their widths/change flags and every
existing semantic event, outcome, address and reason. Each trial records its
derivation and source identity. The immutable original remains in the
[complete F002 archive](https://chatgpt.com/library?file_id=libfile_b995297031a48191b85edf8470091000&account_id=personal)
at `publication/world-history-D006/proposed/docs/evidence/syndicate-world-history-2026-11-01/qualified-other-damage.json`.
Use the sanitized fixture as the explicit evidence argument to
`import_recorded_conditions.py`; its three-trial shape is unchanged. The omitted
preparation writes cannot be validated or reproduced from this derivative.

The handoff's historical review search found older !35 but no D003-D006 findings
review. !35 is now merged and preserves the older audio/graphics/LE work; its
presence does not implement these tactical/history changes. This source import
does not claim a general subscriber, ordinary-player perception or exhaustive
damage coverage. Prior native numbers remain historical.
