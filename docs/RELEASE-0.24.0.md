# fDisBull 0.24.0

The 0.24.0 source adds bounded core replies with private output
handles, integrates the reviewed Z scene/player and original-backed DinoPark
provider, and refreshes the investigation skill with a research-led workflow.
This file records source finalization. Ordinary and native Linux CI must pass
on the exact release commit before tagging. Publication and system installation
are separate actions and are not claimed here.

Core CLI replies default to 65,536 bytes including their newline. Large results
retain their original JSON and return an explicit incomplete-delivery marker.
Projectless inspection, small JSON Pointer selection, byte ranges and private
export work after process exit. Execution outcome remains separate from output
delivery; a missing artifact never authorizes repeating a native action. Private
POSIX locking, content hashes, per-artifact/store quotas and no-clobber exports
protect retained evidence. Unsupported private storage fails explicitly. See
[output handling](OUTPUT_LIMITS.md).

PR #18 and #19 were integrated in dependency order only after both exact
heads passed ordinary and native Linux CI. Their merge ancestry is preserved.
The Z service runs authored shared-IL scenes; the standalone player remains
separate from core analysis and consumes a bounded public view. The DinoPark
provider reconstructs the user's qualified original files through the DOS UDC,
then sends original game inputs. It does not replace financial rules or claim
recovered game semantics. Blank and whitespace backend commands now produce a
clean usage error before attempting a connection.

The skill adds edition-qualified prior-work research, a guide-derived progression
checklist, hidden-object leads, negative/alternate paths and source-to-UDL/UIL
evidence boundaries. Guide order is not automatically a dependency; an authored
checklist is not independent corroboration of its source. Keep unobserved hidden
contents out of public player narration. Budget research by expected decision
value, cost and confidence, and count preparation time when comparing recovery
methods. The broader PR #20 adapter proposals remain separate work.

Ordinary CI now gates skill discovery, front matter, every indexed resource and
local link using an isolated installation of the built wheel. Native offline-kit
CI repeats the gate against its installed package. Package audits require the
new reference and gate script, and both native profiles include the new output,
skill and provider integration tests.

Fresh native DinoPark save/load, installed-package checks and remaining platform
limits are recorded in [verification](VERIFICATION-0.24.md). Game/story files,
native states, saves, databases and full retained outputs remain outside Git and
tool archives. Exact-commit ordinary/native CI, tagging, publication and system
installation remain separate release steps.
